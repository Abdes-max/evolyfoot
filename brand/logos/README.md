# Logos EvolyFoot

Monogramme EV : un E en trois ailes avec le ballon au centre, et un V incliné, en blanc sur un dégradé horizontal.

| Fichier                                       | Usage                                      |
| --------------------------------------------- | ------------------------------------------ |
| `evolyfoot-logo.svg`                          | Logo complet, à privilégier partout        |
| `evolyfoot-logo-1024.png`, `512`, `192`, `64` | Mêmes logos en PNG, fond transparent       |
| `evolyfoot-monogramme-blanc.svg`              | Monogramme seul, sur fond sombre ou coloré |
| `evolyfoot-monogramme-encre.svg`              | Monogramme seul, sur fond clair            |
| `evolyfoot-coach-icone.png`                   | Icône de l'application EvolyFoot Coach     |
| `evolyfoot-player-icone.png`                  | Icône de l'application EvolyFoot Player    |

Couleurs : bleu `#12a8f0`, vert `#5fd62f`, encre `#062330`, fond sombre `#070b12`.

Copies utilisées par les applications : `apps/web/src/app/icon.svg` et `design-impact.css` pour le web, `assets/` de `apps/mobile` et `apps/mobile-player` pour les applications.
